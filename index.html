Homovore+

A Fabric client for Minecraft. Simple, fast, with its own modules.

↓ Download 0.6.0 · Fabric 1.21.11

Requirements

Minecraft 1.21.11 with Fabric Loader and Fabric API. Java 21.

Installation

  1. Install Fabric Loader
  2. Drop the jar into mods/
  3. Launch the game

Ready

No setup needed, settings save themselves. Open the menu with the key from the Client tab.
